# AX 해커톤 실전 플레이북 (범용)

> 대상: 첨부 자료를 근거로 서술형 산출물(보고서·기획안·판단서·메일 등)을 쓰는 과제, AI 사용 제한(횟수 N회·질문당 M자), **결과 + 과정(프롬프트)** 동시 평가.
> `N`, `M`, `T`(제한 시간)는 실제 규칙으로 바꿔 읽는다. 예시는 N=10, M=1,000자(공백 포함 가정), T=100분.

**순서**: 1장 → M0(또는 M0+) → F → 3장 모듈 → V → 12장

## 0. 7대 원칙

| 원칙 | 행동 |
|---|---|
| 1. 자립형 프롬프트 | AI의 기억 여부와 무관하게 매번 역할·자료·규칙을 다 쓴다 |
| 2. 횟수 = 예산 | 탐색 1 → 사실 고정 0~1 → 분석 → 검증 1~2 → **예비 1은 끝까지 남김** |
| 3. 프롬프트도 답안 | 과정도 평가되므로 항상 7개 태그(`#역할 #목표 #자료 #확정사실 #작업 #제약 #출력`) |
| 4. 자료 선별 | 회차마다 필요한 파일만 첨부, 파일명·용도 명시 |
| 5. 근거 강제 | 모든 결론에 교차검증 + 위치(행/페이지/조항/줄) + 원문 1구절 |
| 6. 비식별화 | 식별정보 파일은 기본 미첨부(1-5). 출력은 가명·코드명·집계만 |
| 7. 조립은 사람이 | AI는 장 단위 재료만, 최종 조립·다듬기는 편집기에서 내가 |

## 1. 문제 받자마자: AI 쓰기 전 체크리스트 (T의 10%)

- [ ] **1-1. 규칙 확인**: N, M(공백·붙여넣기 포함?), T, 실패 응답 차감, 응답 길이 상한, 첨부 방식·개수·형식, 새 대화 가능, 답안 분량, 편집기 기능.
- [ ] **1-2. 산출물 형태 확정**: 보고서 / 기획안 / 의사결정 메모 / 메일·공지 / 표 / 발표 개요. 필수 섹션이 있으면 **제목·순서 그대로** `## 제목` 뼈대를 깐다. 없으면 지문의 단위(메일 단락, 첨부 표 등)나 결론 → 근거 → 대안·권고 → 실행·리스크를 섹션으로. 맨 아래 `## 메모`(제출 전 삭제).
- [ ] **1-3. 지문 해부**: 메모에 채운다. 굵은 글씨·숫자·고유 용어는 채점 키워드로 본다.

  ```
  나의 역할:            보고 대상/마감:
  산출물 분량·형식: (글자수, 표 개수·위치)
  핵심 수치: 기준값(목표/전기/벤치마크)·현재값·격차 | 의사결정형: 선택지·판단 기준·제약
  요구 동사: (진단 / 원인 / 비교 / 제안 / 정당화 / 계획 / 판정 / 작성)
  지문 고유 프레임·용어: (예: "N단계", "우선순위")
  제약 조건: (예산 한도, 규정, 일정)
  ```

- [ ] **1-4. 자료 분류**: 파일명으로 나누고 Q1에서 보정.

  | 종류 | 예 | 주 용도 | 자주 숨은 함정 |
  |---|---|---|---|
  | 정량 | csv, xlsx, 실적·로그 | 계산·추세·분해 | 평균 산식, 기간·단위 불일치, 합계 불일치, 다중 시트 |
  | 규정·기준 | 규정·정책·계약 pdf | 판정 기준, 의무·기한 | 예외 조항, 기한 기산일 |
  | 서술·의견 | 회의록·메일·메신저·인터뷰 | 주장·결정·일정 | 의견을 사실로 착각, **번복된 결정** |
  | 외부 비교 | 벤치마크, 타사·타기관 사례 | 위치 평가, 도입 요소 | 조건(규모·예산) 차이 무시 |
  | 시각자료 | 차트·이미지·스캔 | 추세·분포 | AI 오독 → 수치는 직접 읽어 `#확정사실`로 |

- [ ] **1-5. 민감정보(첨부 전)**: 이름 → `[직원1]`, 유일 직위 → `[경영진A]`, 발신자 → `[발신자1]`, 거래처 → 지문 코드명(없으면 `[거래처A]`). 고유번호·연락처·건강정보·개인별 수치는 쓰지 않음(집계만, 5명 미만은 `<5`). 식별정보 파일은 기본 미첨부(집계는 뷰어에서 직접 → `#확정사실`). 꼭 필요하면 그 회차만 첨부하고 `#제약` 첫 줄에 "{번호}의 {식별 열} 인용·출력 금지, 집계만". 미첨부 사유는 `#자료`에 1줄.
- [ ] **1-6. 매핑 + 회차 배분**: 3장으로 모듈, 2장으로 N회 배분. 분석은 의존 순(사실·현황 → 규정 판정 → 대안 평가 → 설계·재무 → 실행 계획), 답안 배치는 지문 순서.

## 2. 범용 파이프라인

| 단계 | 목적 | 회차 수 | 산출물 |
|---|---|---|---|
| ① 탐색 | 자료 지도·타임라인·상충 | 1 (N≤6: M0+로 ② 겸함) | 메모 |
| ② 사실 고정 | 유효 결정·예산·일정·정의(F) | N≥7: 1 | 확정사실 |
| ③ 분석 | 섹션별 모듈 실행 | 나머지 | 장별 초안 |
| ④ 검증 | 재검산, 논리·인용·비식별 | N≤7: 1(V통합), 그 외 2 | 수정 목록 |
| ⑤ 예비 | 잘림·오류 재작성, 보강 | N≤4: 0, 그 외 1 | — |

예: N=4 → 1·0·2·1·0 / N=6 → 1·0·3·1·1 / N=10 → 1·1·5·2·1

- 섹션 수 > ③이면 같은 자료·앞뒤 의존이 있는 섹션끼리 묶는다. 묶음·모듈 2개 회차는 `#작업` 5개 이하(표 항목 우선, 검산은 V로), `#확정사실`은 그 섹션 전제만. 그래도 5장 예산을 넘으면 묶지 말고 ④를 V통합 1회로.

## 3. 섹션 → 모듈 매핑 규칙

섹션 제목(없으면 과제 문장)의 **동사·명사**로 모듈을 고른다.

| 이런 말이 있으면 | 모듈 |
|---|---|
| 현황, 진단, 효과성, 성과, 실적, 추이, 불만·문의 | M1 계산·진단(유형별 비중은 +M3) |
| 원인, 문제점, 근본, 왜, 저하·미달 요인 | M2 원인 판정 |
| 기여도, 영향도, 비중, 요인별, 정량화 | M3 분해 |
| 벤치마크, 포지셔닝, 사례, 경쟁, 외부 비교 | M4 비교 |
| 이해관계자, 관점, 갈등, 수요, 니즈, 요구 | M5 관점 정리 |
| 규정, 준수, 위반, 의무, 계약, 법, 기준 충족 | M6 규정 판정 |
| 대안, 선택, 우선순위, 의사결정, 타당성 | M7 대안 평가 |
| 개선안, 전략, 설계, 구조, 방안, 대책, 제안, 정책 | M8 설계 |
| 예산, 배분, 비용, ROI, 효과, 투자 | M9 재무 |
| 리스크, 로드맵, 일정, 실행, KPI, 계획, 추진, 도입 | M10 실행 계획 |
| 요약, 메일, 공지, 보도자료, 경영진 보고 | M11 문서화(내용은 다른 모듈로 먼저) |

- 대안·선택은 M7 우선(M4는 외부 사례일 때 보조). 후보 목록 파일이 있으면 M7 추가, 규정 파일이 있으면 표에 '규정 충족' 열.

## 4. 첫 프롬프트도 AI에게 쓰게 할까?

**시험 전에 템플릿을 확정하고(이 문서), 시험 중에는 메타 프롬프트("프롬프트 써 줘")에 회차를 쓰지 않는다.**

- 결과가 파일 근거 약한 일반론이 되기 쉽고, 다시 붙여 넣으면 M자를 잡아먹는다. 직접 설계한 지시가 과정 평가에도 유리할 가능성이 높다.
- 대신 **Q1에 "섹션별 필요 파일·쟁점"을 넣어** 분석 계획을 겸한다.

## 5. 프롬프트 골격과 블록

`{…}`만 채운다. 가명은 `[역할+번호]` 형식만. `#자료`에서 `01=정식 파일명`으로 한 번 쓰고 이후 번호로 줄인다.

```
#역할
너는 {도메인} {전문 분야} 전문가다.
#목표
'{섹션 제목}' 작성용 분석. {한 줄 목적}
#자료
첨부만 사용: {01=파일명}(용도: {…}), {02=파일명}(용도: {…}). 파일 밖 지식은 '추정' 표기.
#확정사실
{이월 메모 / 없음}
#작업
1) {…}
2) {…}
3) {…}
#제약
{제약 블록}
#출력
{출력 블록}
```

**제약 블록 (M>1,000)**
```
- 결론마다 다른 파일 1개 이상과 교차검증(일치/불일치), 근거=(파일, 행/p./조항/줄)+원문 1구절
- 수치는 원자료로 재계산, 계산식 병기
- 사실/해석/가정 구분, 상관≠인과, 날짜 선후 확인, 번복 결정은 최신만
- 식별정보는 가명·코드명, 개인별 값은 집계만(5명 미만 <5)
```

**축약 제약 블록 (M≤1,000)**
```
- 결론마다 교차검증+근거(파일,위치,원문)·재계산식 / 사실·해석·가정 구분, 날짜 선후, 최신 결정만 / 가명·집계만(<5)
```

**출력 블록**
```
표 {n}개 + 개조식 본문. 마지막에 '확정사실' 3줄([태그] 사실 (출처), 줄당 60자 이내).
```

**길이 예산(공백 포함)**: 전체 M×0.85 이하, `#확정사실` min(300, M×0.2) 이하. 넘으면 ① 용도 괄호 삭제(파일 6개 이상·2회차부터) ② `#역할` 한 줄·목적 생략 ③ `#작업` 축소. 빈 골격+축약 블록+모듈만 280~390자라 M<600이면 태그를 한 줄에 몰고 `#작업` 2개로.

## 6. 모듈 템플릿

M1~M10·F는 `#작업`만 바꾼다. M0·M0+는 `#목표`·`#출력`도, M11·V는 단독 형식(제약·출력 블록 없음).

**M0 탐색 (Q1, 1-5 제외 파일 빼고 첨부)**
```
#목표 산출물 작성 전 자료 지도. 해석·결론 금지.
#작업
1) 파일별: 파일명|종류|기간·작성일|핵심 항목|이상·결측|민감정보 위치(값 출력 금지)
2) 핵심 사건 15개 이내 타임라인: 날짜|사건|출처
3) 파일 간 상충 수치·주장, 이후 번복된 결정
4) 섹션별 필요 파일과 쟁점: {섹션 제목 나열}
#출력 표 4개
```

**M0+ 탐색·사실 고정 (N≤6)**
```
#목표 자료 지도·사실 확정. 해석·결론 금지.
#작업
1) 파일별: 파일명|종류|기간|민감정보 위치(값 출력 금지)
2) 사건 10개 타임라인, 상충·번복은 유효/폐기
3) 섹션별 필요 파일·쟁점: {섹션 나열}
4) 유효 예산·일정·지표 정의 확정, 합계 재계산
#출력 표 3개 + 확정사실 3줄
```

**F 사실 고정**
```
1) 결정·발언·금액 날짜순, 번복된 것 '폐기' / 최종 '유효'
2) 핵심 지표 정의식·기준기간 경계(자료마다 다르면 모두)
3) 변경·사건: 일시|내용|승인 여부|출처
4) 유효 예산·일정·제약 합계 재계산
```

**M1 계산·진단**
```
1) 전체·{그룹/기간}별 {지표}를 원자료로 재계산, 기준값({목표/전기/벤치마크}) 대비 격차
2) 지문 수치 {값들} 재현 확인, 다르면 원인(산식·결측·기간)
3) 추세·{그룹} 간 차이와 기준기간 차이(사전 격차) 분리
4) {강점·한계 / 악화 상위 항목} 각 3
```

**M2 원인 판정**
```
1) 자료에 나온 원인 주장·후보 전부(주체는 부서·역할 코드)
2) 판정표: 후보|발생 시점(해당 시)|결과 시작 시점|시점상 가능?|원인/증상|지지·반박 근거|판정(근본/기여/증상/기각)
3) 교란요인으로 층화하면 사라지는 차이는 '상관'으로 분리
4) 근본원인과 우선순위 2~3위, 확신도
```

**M3 분해 (기여도)**
```
1) 전체 격차를 {요인/항목/그룹}별로 분해(시계열: 기준기간 vs 문제기간 / 그룹: 비중×격차)
2) 요인이 겹치는 단위는 교집합 행으로 분리, 합계=전체 격차 검산(초과는 중복, 미달은 '미분류')
3) 요인별 기여(비율 지표는 %p, 금액·건수는 절대값)·비중%, 계산식, 기준 선정 이유
```

**M4 비교 (벤치마크)**
```
1) 비교표: 대상|규모·조건|지표·값|측정 방식|근거
2) 지표 정의가 다르면 '비교 불가', 같은 기준끼리만 순위
3) 우리 위치·격차, 강점·약점 각 2
4) 도입 가능 요소 vs 조건 차이로 불가한 요소
```

**M5 관점 정리 (해석 금지)**
```
1) 관점 매트릭스: {주체 4~6} × 문제 인식·선호 해법·이해관계·우려
2) 주체별 주장과 그 근거 위치만(판정 금지)
```

**M6 규정 판정**
```
1) 관련 조항 목록: 조항|요건|기한·기산일|예외
2) 사실관계를 조항 요건에 대입: 사실|조항|충족/위반/판단불가|근거
3) 위반 시 필수 조치와 기한(기산일 해석이 갈리면 두 해석 모두)
```

**M7 대안 평가**
```
1) 대안 목록(현행유지=기준선 포함)과 평가 기준(지문·규정에서 도출, 가중치 근거)
2) 평가표: 대안|비용(총액·산식)|효과(기준선 대비)|기준별 점수·근거|제약 충족|총점
3) 제약 위반 대안 제외 사유, 최적안과 차선안
```

**M8 설계 (개선안)**
```
1) 대책표: 대책|겨냥 원인·요구|대상|규모|기대 효과(수치)|근거
2) 지문이 지정한 구조 반영: {지정 구조, 없으면 단기·중기}
3) 원인 우선순위와 대책의 1:1 대응 확인
```

**M9 재무**
```
1) 유효 한도 안 배분표, 합계 재검산(초과 금지)
2) 효과·비용·ROI·회수기간: 지문·규정의 정의식 사용, 없으면 정의를 명시
3) 보수/기준/낙관 시나리오, 가정 전부 열거
4) 제외안과 그 이유
```

**M10 실행 계획**
```
1) 리스크표: 리스크|가능성|영향|근거|대응|담당 부서
2) {시작}~{보고·마감} 단계별 일정: 단계|기간|조치|산출물
3) KPI {3~5}개: 지표|측정법|기준값(근거)|목표값. 보고 시점에 측정 불가하면 선행지표
4) 시점상 불가능한 일정·지표 자체 점검
```

**M11 문서화 (톤·형식 변환)**
```
아래 확정사실만으로 {메일 / 공지 / 요약}을 {n}자 이내, {지정 형식}으로 작성. 새 사실 금지, 출처 (파일번호), 가명 유지.
#확정사실 {붙여넣기}
```

검증 골격 = `#역할 #자료 #검증대상/#점검문장 #출력`. AI가 기억하는 환경이면 새 대화에서 실행해 앞선 답에 끌려가지 않게 한다.

**V1 수치 검증**
```
#역할 독립 검증 감사관. 이전 대화는 무시, 첨부 원자료로만 재계산. 새 분석 금지.
#자료 {01=파일명, …}
#검증대상 {10개 이내 '항목: 값 (파일번호, 행)'}
#출력 표: 항목|초안 값|재계산 값|일치|원자료 위치|계산식. 인용 위치가 틀리면 '인용 오류'. 문제 없으면 '이상 없음'만.
```

**V2 논리·인용·비식별 검증**
```
#역할 비판적 검토자. 이전 대화는 무시.
#자료 {01=파일명, …}
#점검문장 {5개 이내, 문장당 80자 이내}
#작업 문장별: 상관→인과? 시점 역전·폐기 결정 인용? 의견의 사실화? 인용이 내용을 뒷받침? 식별정보 잔존?
#출력 문장|판정|문제 유형|근거|수정 문장. 문제 없으면 '적합'만.
```

**V통합 (검증 1회)**
```
#역할 독립 감사관. 이전 대화는 무시, 첨부 원자료로만. 새 분석 금지.
#자료 {01=파일명, …}
#검증대상 {수치 7개 이내 '항목: 값 (파일번호, 행)'}
#점검문장 {3개 이내}
#작업 수치 재계산·위치 대조, 문장은 V2 점검 항목
#출력 표1 항목|초안|재계산|일치|위치 / 표2 문장|판정|문제|수정. 문제 없으면 '이상 없음'만.
```

**R 예비 (상황별)**

| 상황 | 방법 |
|---|---|
| 출력 잘림 | 받은 결과를 2~3줄로 줄여 `#확정사실`에 넣고, `#작업`은 남은 번호만, `#출력` "표 1개, 본문 5줄" |
| 검증 오류 다수 | 해당 회차 프롬프트 재사용 + `#확정사실`에 수정사항, 무관한 줄 삭제 |
| 여유 있음 | 근거가 가장 약한 장 재작성 |

## 7. 이월 메모 (AI가 기억하지 못한다고 가정하고 결과 넘기기)

'확정사실'을 `## 메모`에 한 줄씩 쌓는다.

```
[수치] {지표} {값} (기준 {값}, 격차 {값}) (01 행3~40)
[원인] 근본원인 = {요인}({날짜}) — 결과 시작 {날짜} (03 행8)
[기각] {가설}: 결과 시작 이후 발생 → 원인 아님 (03 행12)
[유효] 예산 {값}({날짜} 수정안), 1차안 폐기 (10 줄45)
```

- 한 줄 = 사실 1개 + 출처, 60자 이내. 다음 회차엔 필요한 줄만(5장 예산), 식별정보 확인.
- AI 수치는 1~2개라도 뷰어에서 직접 대조 후 메모에.

## 8. 함정 사냥표 (자료 기반 과제의 흔한 함정)

| 함정 | 증상 | 잡는 지시 (프롬프트에 한 줄) |
|---|---|---|
| 시점 역전 | 지목된 원인이 결과보다 늦게 발생 | "후보별 발생일과 결과 시작일 비교" |
| 증상↔원인 혼동 | 결과 지표 악화를 원인으로 지목 | "원인/증상 구분 열 추가" |
| 상관≠인과·교란 | 그룹 차이가 다른 변수 탓 | "{변수}로 층화해도 차이가 남나" |
| 평균의 함정 | 단순/가중 평균, 그룹 구성비 차이 | "산식 명시, 가중 기준 재계산" |
| 기간·단위 불일치 | 월/주, %와 %p, 억/백만 | "기간·단위 통일 후 계산" |
| 합계 불일치·요인 중첩 | 분해 합 ≠ 전체, 겹친 요인 이중계산 | "교집합 행 분리, 합계 검산, 차이는 미분류" |
| 번복된 결정 | 1차안·수정안 공존 | "날짜순 정렬, 유효/폐기 표기" |
| 의견의 사실화 | 주장을 근거 없이 채택 | "주장과 데이터 근거 분리" |
| 규정 기한·예외 | 기산일·예외 조항 누락 | "조항별 요건·기한·예외 표" |
| 벤치마크 조건 차이 | 조건 다른 사례를 그대로 적용 | "조건 차이와 도입 가능 여부" |
| 측정 시점 | 보고일에 측정 불가한 성과 | "보고 시점 측정 가능성" |
| 정의 부재 | 지표 정의가 자료마다 다름 | "자료의 정의식 사용, 없으면 명시" |

지문 고유 프레임·용어(예: N단계)는 항목명을 **섹션·문장에 그대로** 쓴다.

## 9. 답안 작성 규칙 (결과 평가 대응)

- 결론 먼저, 근거 다음. 섹션 제목·순서는 지문 그대로(없으면 1-2).
- 인용 통일: `(근거: 파일명 N행 / p.N 제N조 / N줄)`. 분량 제한 시 본문은 `(파일번호)`, 상세는 표로.
- 판정 문장: "{기준(규정·목표·지문 조건)}에 따라 {데이터 위치}를 검증한 결과 {결론} (근거: "원문")"
- `[사실] / [해석] / [가정]` 구분. 가정은 수치로 명시.
- 기각 가설 한 줄: "{가설}은 {근거}로 기각". 번복: "{1차안}({날짜})은 {수정안}({날짜})으로 대체되어 수정안을 따른다".
- 비식별 문구 1줄: "본 문서의 개인·고객·거래처 식별정보는 가명·코드명으로 처리함."

**형식별** (지문 지정이 우선)

| 형식 | 요약 위치 | 표 |
|---|---|---|
| 보고서·기획안 | 맨 앞 5줄(결론→우선순위→핵심 수치→실행→효과), 요약 섹션이 없으면 첫 섹션 위 | 섹션마다 1개+ |
| 메일·공지 | 첫 문단 2~3줄 | 근거는 첨부 표 |
| 의사결정 메모 | 첫 줄 권고안 | 대안 비교표 1개 |
| 표·발표 | 표·첫 장 위 1~2줄 | 지정 개수 |

## 10. 시간 배분 (T 대비 비율)

| 구간 | 비율 | 할 일 |
|---|---|---|
| 준비 | 10% | 1장 체크, 뼈대·메모 |
| 탐색·사실 고정·분석 | 45% | 받은 출력은 즉시 해당 장에 붙이고 메모 갱신 |
| 조립 | 20% | 요약, 키워드 문장, 인용 통일 |
| 검증 | 15% | V 실행과 반영 |
| 마감 | 10% | 12장 체크, 메모 삭제 |

응답 대기 중엔 다음 프롬프트 작성, 직전 수치를 원자료와 대조.

## 11. 위기 대응

| 상황 | 대응 |
|---|---|
| AI 수치 ≠ 원자료 | 원자료 우선. 메모에 `[불일치]`, V 대상에 추가 |
| 없는 행·페이지 인용 | 직접 찾은 위치로 교체, 없으면 '추정' |
| 횟수 부족 | 섹션 묶기(2장), 검증은 V통합 1회 |
| 응답이 얕음 | 첨부 2~3개, 섹션 하나로 좁힘 |
| 개인정보를 입력함 | 되돌릴 수 없다고 가정. 이후 철저히 가명, 매 출력 Ctrl+F(기억 시 재출현) |
| 시간 부족 | 모든 섹션에 결론 1줄 + 근거 1개는 반드시 |
