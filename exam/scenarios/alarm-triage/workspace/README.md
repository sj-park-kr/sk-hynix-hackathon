# 실무형 과제 — 설비기술팀 알람 업무 도구

## 상황

가온메모리(가상 회사) M3 팹 설비기술팀에서 "교대 근무 중 설비 알람 업무를 도와줄 도구"를 요청했습니다.
요청한 사람은 화면 오른쪽 채팅창의 **실무자**입니다. 실무자는 개발자가 아니고, 이 폴더의 파일을 볼 수 없습니다.

## 할 일

1. 실무자와 대화해 실제 문제가 무엇인지 정의하세요. 실무자는 필요한 것을 한 번에 다 말해 주지 않습니다.
2. 실무자가 **내일부터** 쓸 수 있는 도구를 만드세요.
3. 다음 담당자가 이어받을 수 있게 결과물과 문서를 정리하세요.

## 제공 자료

| 경로 | 내용 |
|------|------|
| `uploads/logs/etch_*.csv` | 식각 설비 알람 로그 (설비 모니터링 시스템에서 내려받은 파일) |
| `uploads/logs/cvd_*.csv` | 증착 설비 알람 로그 (설비사 서버에서 내려받은 파일) |
| `uploads/alarm_manual_v2.3.md`, `uploads/alarm_manual_v3.0.md` | 알람 조치 매뉴얼 |
| `uploads/pm_schedule.csv` | 설비 PM(예방정비) 일정 |
| `uploads/handover_memo_example.txt` | 지금 쓰고 있는 교대 인계 메모 예시 |
| `docs/` | PRD(파트장이 예전에 쓴 초안), ARCHITECTURE·DECISIONS·ROADMAP 템플릿 |
| `AGENTS.md` | 팀 공통 AI 에이전트 규칙 (필요하면 보완) |

기본 골격은 Vite + React + TypeScript입니다(`npm install` 후 `npm run dev` / `npm run build` / `npm test`). 다른 방식이 낫다면 바꿔도 됩니다. 이유는 `docs/DECISIONS.md`에 남기세요.
모든 회사·사람·데이터는 가상입니다.

## 시간

200분.

## 제출 기준

- **동작하는 결과물**: 실행 방법이 문서에 있고, 실제로 실행됩니다.
- **docs/ 갱신**: 합의한 내용, 구조, 결정 이유, 남은 일.
- **의미 있는 커밋**: 작업 단위마다 무엇을, 왜 바꿨는지.

## 평가 안내

- 결과물, 수행 과정(실무자 대화와 AI 활용), 본인이 만든 것에 대한 이해도를 봅니다.
- 종료 후 사후 Q&A가 있습니다. **AI 없이** 문항당 3분 안에 직접 답합니다.
