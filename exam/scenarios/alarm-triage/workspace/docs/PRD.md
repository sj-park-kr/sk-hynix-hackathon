# PRD — 설비 알람 정리 도구 (초안)

> 작성: 설비기술팀 파트장 · 2026-09-15 · 상태: **초안, 현업 확인 전**
> 과제 수행자는 실무자와 합의한 내용으로 이 문서를 고쳐 쓴다.

## 1. 배경

- 교대 근무 중 설비 알람이 많아 엔지니어 부담이 크다.
- 알람을 확인하고 정리하는 방식이 사람마다 다르다.

## 2. 목표 (초안)

- 식각·증착 설비 알람을 한눈에 볼 수 있는 **실시간 알람 대시보드**를 만든다.
- (추가 목표는 현업 인터뷰 후 정리)

## 3. 사용자

- 설비기술팀 교대 엔지니어

## 4. 가정 (초안)

- 알람 등급은 「알람 조치 매뉴얼 v2.3(최종본)」 기준으로 분류한다.
- 설비 알람 로그의 시간은 모두 한국 시간(KST)으로 기록된다.
