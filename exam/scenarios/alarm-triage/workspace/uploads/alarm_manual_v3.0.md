## 3. 비고

- 설비 로그의 알람 문구는 벤더마다 다르다. 코드 기준으로 본다.

## 4. 연쇄 알람

- P-1001(진공펌프 이상) 발생 후 **5분 이내** 같은 설비에서 발생한 E-1203, E-2107, W-0502는 P-1001의 연쇄 알람으로 본다.
- 연쇄 알람은 별도 건으로 세지 않고 P-1001 건에 묶어 기록한다.
