# PRD — 박막 SPC 모니터링 도구 (초안)

> 작성: 박막기술팀 파트장 · 2026-09-18 · 상태: **초안, 현업 확인 전**
> 과제 수행자는 실무자와 합의한 내용으로 이 문서를 고쳐 쓴다.

## 1. 배경

- 막 두께 계측 데이터가 많아 엔지니어가 SPC 이탈을 확인하는 데 시간이 많이 든다.
- 이탈 여부를 확인하는 방식이 사람마다 다르다.

## 2. 목표 (초안)

- 계측 데이터를 자동으로 모아 **실시간 SPC 차트 대시보드**로 보여 준다.
- (추가 목표는 현업 인터뷰 후 정리)

## 3. 사용자

- 박막기술팀 공정 엔지니어

## 4. 가정 (초안)

- 판정 기준은 「박막 SPC 관리 기준표 rev.B(확정)」를 따른다.
- 계측기 두께 값은 모두 Å 단위로 기록된다.
- 하루 데이터는 0시부터 24시까지로 집계한다.
