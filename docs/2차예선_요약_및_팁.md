1. **10/31(토) 9:40까지 접속.** 과제는 10:00에 시작하고, 서술형까지 포함한 모든 응시가 **14:00에 끝납니다.** 늦게 들어와도 연장되지 않습니다. 개인 응시 링크는 **10/29(목)** 메일로 옵니다.
2. **과제에 쓸 수 있는 AI는 응시 환경에 제공된 Codex뿐입니다.** Claude Code, 개인 API 키, 개인 유료 구독, Astra 모델은 쓸 수 없습니다. 권장 모델은 Sol 6.1, Terra 5.6, Luna 6, Sol 6.0입니다.
3. **사전 체험은 1회, 15분뿐입니다.** 실제 응시할 장소와 장비로 해야 합니다.
4. **'과제 시작'을 누르면 녹화와 180분 타이머가 함께 시작됩니다.** 휴대폰 거치와 신분증·안경 검사도 이 시간 안에서 진행됩니다.
5. **후속 서술형은 AI 사용과 복사·붙여넣기가 금지됩니다.** 6문항이고 문항당 5분이며, 이전 문항으로 돌아갈 수 없습니다. 질문은 제출물과 작업 기록을 바탕으로 만들어집니다.
6. **모니터는 1대만 씁니다.** 화면 공유는 "전체 화면"으로 해야 하고, 브라우저 전체화면이 강제되며 캡처 단축키를 누르면 감지됩니다.
7. **Git push, 외부 전송, 개인 PC 파일 업로드는 안 됩니다.** 공개된 Skill·MCP·Plugin과 GitHub 공개 저장소 clone은 허용됩니다.

### ② 1_시험 필수확인사항 브리프
- **진행 순서:** 과제풀이(최대 180분) → 서술형 준비 대기(약 5분) → 후속 서술형(6문항 × 5분 = 30분)
  - 대기 시간은 풀이 시간에는 포함되지 않지만 전체 응시 시간에는 포함됩니다. 서술형은 '시작'을 눌러야 타이머가 시작됩니다.
- 최소 응시 시간은 없습니다. 일찍 제출하고 서술형까지 마치면 녹화가 자동 종료되고 바로 퇴장할 수 있습니다.
- **준비할 것**
  - 혼자 있는 폐쇄 공간, 웹캠
  - 노트북 전원 어댑터와 **휴대폰 충전선 연결은 필수**
  - 컴퓨터와 휴대폰 모두 방해금지 모드
  - 업로드·다운로드 각각 5Mbps 이상

- **금지**
  - 감독·보안 기능 우회
  - Computer Use(자동 조작)
  - 외부 전송: 모니터링되며 유출 시 법적 조치 대상입니다

  - 에이전트 응답 시간을 고려한 시간 안배도 평가 요소입니다.

## 3. 스킬 설치 방법 (시험 환경 Codex 기준)

**규칙:** 일반에 공개된 Skill만 쓸 수 있고, 개인 PC의 Skill 파일은 업로드할 수 없습니다. 외부 브라우저도 쓸 수 없으니 **Codex 안에서** 설치해야 합니다.

**방법 A: 내장 설치 스킬 사용**
```
$skill-installer linear                         # openai/skills 저장소의 공식 큐레이션 스킬
$skill-installer https://github.com/<owner>/<repo>/tree/main/<skill폴더>를 설치해줘
```

**방법 B: 직접 clone해서 복사**
```bash
git clone https://github.com/<owner>/<repo> /tmp/skills
mkdir -p ~/.agents/skills && cp -r /tmp/skills/<skill폴더> ~/.agents/skills/
```

- **Codex가 스킬을 찾는 위치:** `~/.agents/skills`(사용자), `<repo>/.agents/skills`(저장소), `/etc/codex/skills`
  - **사용자 경로(`~/.agents/skills`)를 권장합니다.** 저장소 경로에 두면 제출물에 섞입니다.
- **사용법:** `/skills`로 목록을 보거나 `$스킬이름`으로 직접 호출합니다. description이 작업과 맞으면 Codex가 알아서 고르기도 합니다. 보통 재시작은 필요 없고, 목록에 안 보이면 codex를 재시작하세요.
- **확인할 점:** 시험 환경의 Codex 버전은 알 수 없습니다. 구버전은 경로가 `~/.codex/skills`였던 것으로 알고 있는데, 이 부분은 확인하지 못했습니다. **사전 체험 때 `/skills`로 경로를 꼭 확인하세요.**
- **MCP는 `config.toml`을 직접 고치지 말고 플랫폼의 MCP 탭으로 설정하세요.** 플랫폼 관리 설정을 수정하는 것은 금지되어 있습니다.
- **쓸 저장소 이름은 외워 가세요.** 시험 중에는 브라우저로 검색할 수 없습니다.
- ⚠️ **회색지대:** 내가 만든 스킬을 시험 직전에 GitHub에 공개로 올려서 가져오는 것은 "개인 비공개 Skill 반입 금지" 규정의 취지와 충돌할 수 있습니다. 하려면 **메일 회신으로 먼저 문의하세요.**

## 4. 후속 서술형 대비: 과제 시간 안에 AI로 미리 공부하는 법

질문은 **제출물과 작업 기록(Codex 대화, git log, 테스트 결과)**으로 만들어집니다. 그래서 작업 기록이 곧 시험 범위입니다.

**시간 배분 예시 (180분 기준)**
- 남은 30분: 기능 개발 중단
- 남은 25분: 문서 마무리
- **남은 20분: 서술형 리허설 (약 10분)**
- 남은 10분: 제출 시작

**① 작업하는 동안**
- `AGENTS.md`에 "중요한 결정은 `결정 / 이유 / 버린 대안` 형식으로 문서에 한 줄씩 기록"이라고 지시해 두세요.

**② 리허설용 Codex 프롬프트 (이해도 퀴즈 형식)**
```
이 프로젝트를 내가 제대로 이해했는지 점검하고 싶어. 코드, git log, 문서를 근거로 주관식 퀴즈 8개를 한 문제씩 내줘.
유형을 섞어줘: 왜 이렇게 설계했나 / 다른 방법 대비 장단점 / 어떻게 검증했나 /
특정 입력에서 코드가 어떻게 동작하나 / 남은 한계 / 전제가 틀린 질문 1개.
내가 답하면 틀린 사실만 짧게 짚어줘.
```
- **유형 지정은 빼면 안 됩니다.** 유형 없이 "퀴즈 내줘"라고만 하면 8개가 모두 암기형으로 나왔습니다(실험 결과는 [스킬_모델_실험결과.md](스킬_모델_실험결과.md) 5장).

**③ 코드 이해 점검 프롬프트**
```
핵심 파일 3개를 각각 5줄로 설명하고, 내가 설명하기 어려울 만한 AI 작성 로직 3곳을 짚어줘.
```

**④ 답변 구조 (5분 안에, 3~5문장)**
- **결론 → 근거(파일·함수 이름) → 검증(테스트·수치) → 한계** 순서로 씁니다.
- 복사·붙여넣기가 안 되니 직접 타이핑할 수 있는 길이로 쓰세요.

**⑤ 전제가 틀린 질문이 나오면**
- "제 구현은 X가 아니라 Y입니다. 이유는…"처럼 차이를 먼저 밝히고 설명하세요. 가이드에 이렇게 하라고 명시되어 있습니다.

**⑥ 빈칸은 피하세요**
- 시간이 끝나면 쓴 데까지 자동 확정됩니다. 남은 시간이 1분이면 결론 한 줄이라도 쓰세요.
